# 📊 Reliance Sales Dashboard Analysis

Welcome to the **Reliance Sales Dashboard** project! This repository contains a detailed sales performance analysis and interactive dashboard built using Microsoft Excel to track key business metrics, regional trends, and category performance.

---

## 📌 Key Highlights & Features
- **Executive Summary:** Overview of total sales revenue, units sold, and average order value.
- **Regional Performance:** Comparative breakdown of sales across different regions and cities.
- **Product & Category Analysis:** Identification of top-performing products and sales trends.
- **Interactive Visuals:** Excel Pivot Charts and Slicers for dynamic data filtering.


---

## 📌 Project Overview & Objectives

The goal of this project is to transform raw retail sales data into an executive-ready dashboard to help management answer critical business questions:
- **Revenue Tracking:** What is the total sales revenue, order count, and average order value (AOV)?
- **Regional Performance:** Which regions, states, and cities are generating the highest revenue?
- **Category & Product Analysis:** Which product lines are top-sellers and which are underperforming?
- **Time Trend Analysis:** How do sales fluctuate across months, quarters, and peak promotion periods?

## 🔑 Key Insights & Analytics

1. **Top Performing Regions:** Identified key markets driving over 60% of overall sales volume.
2. **Category Dynamics:** High-margin product categories vs. volume-driven categories mapped using Pareto (80/20) concepts.
3. **Sales Growth Trends:** Seasonal spikes observed during Q3 and festive periods, providing opportunities for inventory management.
4. **Customer Order Patterns:** Evaluated average basket sizes and bulk order trends across different distribution channels.
